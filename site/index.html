同一件事

回到昨晚那个窗口，两种走法

别的 SSH 客户端把 tmux 当成终端里的一个功能：先连上，再敲命令，再找窗口。lightmux 把层级倒了过来——会话就是你要去的地方，终端只是结果。

$ ssh dev@web-prod $ tmux ls api: 3 windows (created Fri Oct 10) deploy: 1 windows monitor: 1 windows $ tmux a -t api # Ctrl-b w ……是哪个窗口来着
  • 先连上
  • 记会话名
  • 敲命令
  • 再找窗口

功能

tmux 之外，够用的都在

主页就是会话树

主机 → tmux 会话 → 窗口，展开就看到。新建、重命名、结束都在这里，不用敲命令。

侧滑切会话

终端里从左边缘一划，拉出来的就是主页那棵树。切窗口终端原地换，不重连，滚屏不丢。

顺手的快捷栏

Ctrl Esc Tab 方向键都在，可增删排序；Ctrl+B d 这样的组合也能做成一个按钮。

主机监控

CPU、内存、磁盘、网速、进程、容器，一眼看清哪台机器在忙。采不到的如实标「不可用」，不拿 0 充数。

文件管理

浏览、上传、下载、重命名、删除，小文本文件直接在手机上改。复用同一条 SSH 连接。

端口转发 + 内置浏览

终端里一出现 http://localhost:5173，底部就浮出「转发它」。在 app 里打开，切回终端看日志也不断。

还有一些小事

  • 断线自动重连网络一恢复就重试，回到原来那个 tmux 会话，滚屏还在
  • 不和电脑抢屏电脑上也 attach 着时，手机切窗口不会把那块屏一起切走
  • 跳板机ProxyJump 多跳，只能从堡垒机进的内网机器照样连
  • 密钥统一管理私钥导入一次，多台主机共用
  • 凭据加密密码和私钥经系统密钥库加密，不落明文
  • 主机指纹首次连接记住，被调包时拦下来
  • 转发只绑本机连咖啡店 Wi-Fi 也不会把内网服务暴露给同网段
  • 其他登录后自动执行命令、深浅主题、终端配色、中英双语、应用内检查更新
